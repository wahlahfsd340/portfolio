# Wasif Wahlah | Front-End Web Developer Portfolio

A modern, animated personal portfolio built with HTML, CSS, Bootstrap 5 and JavaScript. Wasif is a Web Development student at Corvit Systems, Faisalabad, and is looking for a free internship at a software house.

## Features

- Animated hero section with moving gradient background and typing effect
- Light and dark theme toggle (the choice is remembered)
- Scroll progress bar and back-to-top button
- Interactive code window with a "Run wasif.hire()" button
- Skill cards that reveal while scrolling
- Project filter (All, JavaScript, Bootstrap, HTML & CSS)
- Contact form with JavaScript validation, character counter and email app integration
- Copy-email button with toast message
- Fully responsive and respects "reduced motion" settings

## Tech Stack

- HTML5
- CSS3 (variables, animations, flexbox, grid)
- Bootstrap 5
- JavaScript (DOM, events, IntersectionObserver, localStorage, clipboard API)
- Font Awesome and Google Fonts (Sora, Manrope)

## How to Run

This is a static website, so you can simply open `index.html` in a browser.

To preview it through a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Customization

- Text, projects and contact details: `index.html`
- Colors (see `:root` and `[data-theme]` at the top) and animations: `style.css`
- Typing words, form rules and other behavior: `script.js`
